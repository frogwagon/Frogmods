# Warband assets

`elven_leaf_longbow.glb` - one model from the "[FREE] 3D Fantasy Bows Pack"
by Polyy.AI (https://polyyai.itch.io/3d-fantasy-bows-pack), low-poly LOD
version, unmodified. CC0 1.0 Universal (public domain) - no attribution
required, used here as a courtesy. Loaded at runtime by the Warband mod's
"Fantasy Bow" cosmetic (see narrow-one-warband.user.js) as a purely local,
client-side visual swap for your own held B3 - never synced to other
players, never touching a stat.
